# 05 · Riesgos y dudas

Severidad: 🔴 alta · 🟠 media · 🟢 baja. "✅ Resuelto" = el diseño ya lo cubre y queda documentado para que el arquitecto lo valide.

## Los 8 que más importan

1. **R1 — Modelo de Point.** La documentación de la API de Orders solo nombra **Point Smart 1 y 2**. Si hoy usan Point Mini, Air o Pro, la integración no funcionaría con esos equipos.
2. **R12 — Número de WhatsApp.** Usar el número actual del local con la API requiere un partner (BSP). Sin partner, el número **deja de funcionar en la app de WhatsApp Business** y se pierde el historial.
3. **R5 — Transferencias y QR.** No está documentado que aparezcan en la búsqueda de pagos de MP. La bandeja de conciliación podría necesitar un segundo importador (reportes de MP).
4. **R30 — Datos personales (Ley 25.326).** Registro de la base, política de privacidad, servidores fuera del país. Conviene una consulta legal antes de salir a producción.
5. **R2 — Modo PDV.** No está documentado si una terminal en modo integrado puede seguir cobrando "a mano" si el sistema se cae. Hace falta un plan de contingencia.
6. **R19 — Prisma 8.** Sale estable en octubre 2026 y es una reescritura. Arrancamos en Prisma 7 (soporte hasta ~2028) y la migración queda planificada.
7. **R34 — Corte de internet en el local.** El sistema es 100 % online. Necesita procedimiento de contingencia.
8. **R26 — Cloudflare mal configurado.** El "Bot Fight Mode" del plan gratuito bloquearía los webhooks y no se puede excluir una ruta.
